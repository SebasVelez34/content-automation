Privacy Policy

Last updated: May 30, 2026

1. Overview

This Privacy Policy describes how the El Camino del Guerrero content automation tool handles information. This is a private, single-user application and does not collect data from third parties.

2. Data Collected

The application stores only the following data locally on the operator's machine:

  • TikTok OAuth access tokens (used to publish content on behalf of the account owner)
  • Video content and metadata generated for publication

No personal data from TikTok users or viewers is collected, stored, or processed.

3. TikTok API Data

This application uses TikTok's Content Posting API solely to publish video content to the @elcaminodel.guerrero channel. The only TikTok data accessed is the open_id and access token of the authenticated account owner.

4. Data Sharing

No data is shared with third parties. All tokens and credentials are stored locally and never transmitted to external servers beyond TikTok's official API endpoints.

5. Data Retention

Access tokens are stored locally until manually removed. They can be revoked at any time via TikTok's app permissions settings.
